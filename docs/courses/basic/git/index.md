# Git 与开源协作

学习用 Git 保存项目修改，理解分支、提交和 Pull Request，在自己的练习项目中完成一次协作流程。

<p class="course-meta">方向：基础 · 建议先修：文件操作与基本终端使用</p>

## 学习目标

- 分清工作目录、暂存区与提交记录。
- 使用 `status`、`add`、`commit`、`log` 检查并记录修改。
- 在独立分支中完成小改动，理解代码审核与合并的作用。
- 为练习项目补充使用说明与资料来源。

## 适合谁

适合准备参与开源项目、课程小组作业或科协项目的同学。无需提前掌握 Git，建议能打开终端并进行基本文件操作。
