# 参与课程

## 学员

先查看[课程日程](../schedule/index.md)，找到感兴趣的课程，再阅读该次开课页的先修要求与课前准备。线下上课时携带所需设备，课后可以继续通过原页面访问资料。

报名方式和课程交流入口待公布，当前网站不收集报名信息。

## 讲师与资料贡献者

可提交课程介绍、讲义、课件、示例代码及参考链接。请注明适合人群、先修要求和作者署名，供学员判断如何准备。

资料整理方式见[贡献指南](https://github.com/Caspian315/open-security-courses/blob/main/CONTRIBUTING.md)，科协公开联系渠道待公布。

## 从哪里开始

尚未确定方向时，可先打开[Git 与开源协作](../courses/basic/git/index.md)，了解一门课的资料组织方式。
