# 关于课程项目

“开源安全精品课程”是网安科协组织的线下学习项目。本站集中保存公开课程资料，供同学课前准备、课后复习，也方便后续开课继续积累内容。

## 课程形式

线下授课与实践为主，课程资料公开整理在本站。课程按基础、开发、AI、科研和网络安全等方向组织，每门课注明适合人群与先修要求。

## 当前状态

项目正在筹备。本站目前包含一门完整示例课，真实课表、讲师、上课地点和报名方式待公布。
