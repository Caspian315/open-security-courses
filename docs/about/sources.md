# 资料来源与署名

## 网站组织参考

本站参考[清华酒井科协暑培 2026](https://summer26.net9.org/)的课程方向划分和资料组织方式，采用同类文档网站工具。本站由网安科协独立组织，课程、讲师和日程以本站发布为准。

## 建站工具

- [MkDocs](https://www.mkdocs.org/)：将 Markdown 文档生成静态网站。
- [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/)：提供文档布局、导航与搜索。
- [GitHub Pages](https://docs.github.com/en/pages)：托管公开课程主页。

## 课程资料

每门课在开课页末尾列出作者、讲师和参考资料。引用书籍、文档或其他课程时，保留原始链接；第三方资料保留原作者署名及原有许可说明。

当前 Git 示例讲义、示例 PDF 与练习包由本项目原创编写，均明确标注为示例。后续上传材料时，按文件或课程页补充来源和许可。

## 查找资料

站内搜索覆盖网页中的课程标题、介绍与讲义文字。PDF、PPT 和录像通过对应开课页的资料列表查找。
